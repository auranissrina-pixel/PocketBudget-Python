# PocketBudget-Python
PocketBudget adlah aplikasi manajemen keuangan pribadi berbasis CLI (Command Line Interface) yang ditulis dalam bahasa Python.

## Fitur Utama
- **Catat Pemasukkan**: Menambahkan uang masukk ke dalam daftar saldo
- **Catat Pengeluaran**: Menambahkan transaksi dengan sistem validasi batas saldo.
- **Cek Saldo & Riwayat**: Menampilkan sisa saldo dan daftar riwayat transaksi secara *real-timw*.
- **Penyimpanan Otomatis**: Data tersimpan secara permanen dalam file JSON ('pocketbudget_data.json').
